Run locally
1. Install Python 3.12 and open a terminal in the folder with the three files.
2. Create a virtual environment and install dependencies.

       python -m venv .venv

   Windows PowerShell:

       .\.venv\Scripts\python.exe -m pip install -r requirements.txt
       .\.venv\Scripts\python.exe -m streamlit run app.py

   macOS or Linux:

       .venv/bin/python -m pip install -r requirements.txt
       .venv/bin/python -m streamlit run app.py

3. Open the local URL printed in the terminal. Wait for the first session to
   finish training. The model fits are cached while the app process is running.
4. Click Predict quality with the initial values, then switch classifiers and
   predict again. Check Model evaluation for the comparison, confusion matrix
   and per-class metrics. Check Dataset for the partition counts and protocol.

Deploy on Streamlit Community Cloud from GitHub
1. In a GitHub account you control, create a repository for the assignment.
   Choose private visibility if you want to restrict access to the source and
   student information. Keep the three runtime files at the repository root.
2. Commit the files to the main branch. Confirm that the CSV filename matches
   exactly, including its lowercase letters. GitHub's browser upload works
   for these files.
3. Sign in at https://share.streamlit.io/ and connect the GitHub account.
   Grant Streamlit access to the repository if GitHub asks.
4. Select Create app, then Yup, I have an app. Enter the repository owner and
   name, the branch (main if unchanged), and app.py as the main file path.
5. Under Advanced settings choose Python 3.12 and save. The app needs no
   secrets or external APIs. Select Deploy and watch the build log.
6. Open the assigned streamlit.app URL, wait for training, and repeat the local
   smoke checks. If startup fails, use Manage app to inspect the logs. For
   dataset errors verify the CSV is committed beside app.py. For dependency
   errors verify the Python version and that requirements.txt is at the root.
7. Set viewing permissions so the grader can open the app. If access is
   restricted, invite the grader using the app's sharing controls and verify
   access. Include the exact app URL with the Moodle submission after launch.
